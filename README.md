# Fraud detection

O objetivo desse projeto foi aplicar machine learning para a detecção de transações fraudulentas. O processo incluiu as etapas de pre-processamento, divisão da base de treino usando k-fold e aplicação do CatBoost com o fine tuning feito a aprtir do random search. A avaliação do modelo foi realizada a partir de npetricas de área debaixo da curva e matriz de confusão. Um relatório completo encontra-se no pdf
